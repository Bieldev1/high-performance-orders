# High Performance Orders API

Projeto de estudo e portfólio focado em performance de queries SQL Server, análise de execution plan e otimização com EF Core, usando uma API .NET 8 que simula um sistema de pedidos (e-commerce).

## Status

🚧 Em construção — montado passo a passo.

## Git Flow

- `main` → produção (estável)
- `develop` → integração
- `feature/*` → novas funcionalidades, criadas a partir de `develop`

Commits semânticos: `feat:`, `perf:`, `fix:`, `docs:`.
